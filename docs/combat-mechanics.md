# 战斗机制记录

这里记录实现战法时容易混淆的结算口径。新战法如有相同机制，应先核对这里和对应战法的战报。

## 伤害与减伤

- 物理、策略和持续策略伤害包含独立的兵力基础伤害。写着“受到所有伤害降低 X%”的效果，分别作用于受到攻击伤害和受到策略伤害的增减伤区，与神兵天降、大赏三军等增伤加减结算；**不削减兵力基础伤害**。
- 增减伤先在同一个百分比区间相加减，当前模拟器最低保留 10% 的非兵力基础伤害。`src/battle/battleCalcFunc.js` 中的 `getDamageAddition` 是统一入口。
- 已预先计算数值的指挥伤害和持续伤害，在真正受伤时仍可触发健卒不殆的当次减伤。模拟器保留预计算时的兵力基础伤害，并仅调整其余部分。若旧效果未保留快照基础值，则按伤害来源当前兵力估算。

## 士气与概率

- 战法描述内的“X% 几率”可能单独受士气影响，不只战法发动率受影响。判定方取决于效果描述：健卒不殆的减伤按**受伤武将当前士气**修正，每次伤害独立掷一次；除恶务尽的连击按施加者士气修正。
- 士气换算公式及取整实例见 [士气与战法概率](morale-probability.md)。

## 反击与距离

- 反击在承受普通攻击并结算伤害后，对原攻击者造成攻击类型伤害。它不执行普通攻击流程，因此不触发追击、分兵或再次反击，也不按普通攻击的受击事件继续触发。
- 反击者必须存活，且不能处于怯战或混乱；原攻击者须存活并在反击者**自身攻击距离**内。
- 距离以当前仍可战斗的武将排列计算：我方大营—中军—前锋—敌方前锋—中军—大营。前锋与对方前锋相距 1；有人阵亡后立刻移出队列，距离随即重算。
- 分兵伤害直接由相邻目标承受，不按通常的攻击距离判定，也不触发反击。反击、连击触发的普通攻击则要遵守对应距离规则。

## 指挥与被动效果

- 指挥战法在准备回合生效；已施加的指挥效果通常不因施加者阵亡消失。要由具体战法决定持续和清除规则。例如心战为上的全队效果在马谡阵亡后仍有效。
- 郝昭“不动如山”在每回合开始后、郝昭行动前清除自身有害效果，不限制有害效果来自被动、主动还是指挥战法。
