# 战斗机制记录

这里记录实现战法时容易混淆的结算口径。新战法如有相同机制，应先核对这里和对应战法的战报。

## 伤害与减伤

- 物理、策略和持续策略伤害包含独立的兵力基础伤害。写着“受到所有伤害降低 X%”的效果，分别作用于受到攻击伤害和受到策略伤害的增减伤区，与神兵天降、大赏三军等增伤加减结算；**不削减兵力基础伤害**。
- 增减伤先在同一个百分比区间相加减，当前模拟器最低保留 10% 的非兵力基础伤害。`src/battle/battleCalcFunc.js` 中的 `getDamageAddition` 是统一入口。
- 已预先计算数值的指挥伤害和持续伤害，在真正受伤时仍可触发健卒不殆的当次减伤。模拟器保留预计算时的兵力基础伤害，并仅调整其余部分。若旧效果未保留快照基础值，则按伤害来源当前兵力估算。

## 士气与概率

- 战法描述内的“X% 几率”可能单独受士气影响，不只战法发动率受影响。判定方取决于效果描述：健卒不殆的减伤按**受伤武将当前士气**修正，每次伤害独立掷一次；除恶务尽的连击按施加者士气修正。
- 士气换算公式及取整实例见 [士气与战法概率](morale-probability.md)。

## 反击与距离

- 反击在承受普通攻击并结算伤害后，对原攻击者造成攻击类型伤害。它不执行普通攻击流程，因此不触发追击、分兵或再次反击，也不按普通攻击的受击事件继续触发。
- 反击者必须存活，且不能处于怯战或混乱；原攻击者须存活并在反击者**自身攻击距离**内。
- 距离以当前仍可战斗的武将排列计算：我方大营—中军—前锋—敌方前锋—中军—大营。前锋与对方前锋相距 1；有人阵亡后立刻移出队列，距离随即重算。
- 分兵伤害直接由相邻目标承受，不按通常的攻击距离判定，也不触发反击。反击、连击触发的普通攻击则要遵守对应距离规则。

## 追击蓄势与规避

- 势无虚动在每次**尝试**发动追击战法时增加一层追击增伤（每层 40%，最多三层）；判定失败也保留层数，下一次成功发动追击时对该次追击的伤害生效并消耗层数。
- 每次尝试还令下一次实际造成的伤害无视规避。该效果在伤害结算时消耗，因此若追击前由其他效果先造成伤害，会先用于那次伤害。
- 垒实迎击获得的下一次伤害规避在遭遇无视规避时不消耗，留待下一次可规避的伤害。

## 指挥与被动效果

### 烈火焚舟

- 黄盖的追击战法在普通攻击后判定，基础发动率 120%，沿用追击战法的士气修正。
- 第一段燃烧伤害率：`round(150 + max(0, 谋略 - 80) × 150 / 90)`，持续 2 回合。第二段焚烧伤害率：`round(270 + max(0, 谋略 - 80) × 270 / 120)`，持续 1 回合。
- 再次追击同一目标且目标仍有**该黄盖施加的**第一段燃烧时，立即结算尚未发生的各次燃烧伤害，移除旧燃烧，然后让目标及当前队列中相邻的敌军各降低 10 士气，并施加第二段焚烧。距离按存活队列计算；其他武将的燃烧不会触发第二段。

### 敛微穷极（当前推算口径）

- 334.6 谋略时，神兵天降现有公式 `round(30 + 0.15 × (334.6 - 80)) = 68%`，与实战一致，说明参考数值未额外乘士气。
- 敛微穷极增伤 `round(40 + 0.175 × max(0, 谋略 - 80))`，334.6 谋略得到 **85%**。初始波动上限 `round(150 + 0.15 × max(0, 谋略 - 80))`，得到 **188%**；下限为 80%。单个样本不能唯一确定隐藏系数，0.175 与 0.15 是与截图取整值吻合的简洁候选值。
- 截图的 `57.5% » 115.0%` 是 **Lv.1 到 Lv.10 的固定收敛值**，不是最终波动区间。334.6 谋略、Lv.10 时按同一 0.15 成长系数推算为 `round(115 + 0.15 × (334.6 - 80)) = 153%`，最终伤害率乘数固定为 **1.53**。这项成长系数仍需更多实战样本校准。
- 每次策略伤害在收敛前抽取乘数。准备回合初始范围 `[0.8, 1.88]`；波动下限和上限逐回合各向固定值 1.53 推进六分之一。第六回合起两端相等，不再随机抽取；此前的策略增伤仍按每回合结束降低六分之一独立结算。
- 该增伤处于策略伤害加减区，不影响兵力基础伤害；波动只乘策略伤害公式中的伤害率。指挥结算时先施加者可以进入白衣渡江预计算伤害的快照，后施加者不能追溯修改该快照。

- 指挥战法在准备回合生效；已施加的指挥效果通常不因施加者阵亡消失。要由具体战法决定持续和清除规则。例如心战为上的全队效果在马谡阵亡后仍有效。
- 郝昭“不动如山”在每回合开始后、郝昭行动前清除自身有害效果，不限制有害效果来自被动、主动还是指挥战法。
