# 宝物战斗规则

- 分兵视为普通攻击。分兵伤害使用 `isBasicAttack: true`，因此享受元戎「陷阵」的普通攻击增伤；每次分兵命中也会触发「选锋」并计入「蓄锐」的普通攻击次数。
- 元戎「迸发」只在装备者首次发动自己的追击类主战法时生效。额外目标须存活、不同于原目标，并处于装备者当前攻击距离内；携带的第二、第三战法不触发。
- 元戎「奔袭」的发动率在士气修正之后按百分点相加。「坚毅」在指定的前几回合阻止暴走和混乱状态施加。
- 奋髯「奋武」仅在本次普通攻击的正向增伤合计**严格大于**250%时无视规避；250%本身不触发。分兵仍按普通攻击处理。
- 奋髯「强击」只阻止指定前几回合普通攻击引发的反击；「藏锋」在一整回合没有普通攻击后，赋予下一回合首次普通攻击无视防御的效果，该次攻击附带的分兵也适用。
